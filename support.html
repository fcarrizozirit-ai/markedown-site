Support

Questions, problems or ideas: email fcarrizozirit@languageteaching.es. Please include your macOS version and, if something went wrong, the steps that led to it.

Where are my documents saved?

Wherever you choose. MarkeDown saves ordinary .md files in the folder you pick, with no hidden library or database. You can open the same files in any other editor.

What happens to images I paste or drag in?

In a saved document, MarkeDown copies each picture into an assets folder next to the document. Keep that folder with the file when you move or share it. Save the document before adding images; in an unsaved document the picture is stored inside the file, which makes it large.

Will other apps show my colours and highlights?

Markdown has no syntax for text colour, highlighting or alignment, so MarkeDown stores them as small standard HTML tags inside the file. MarkeDown always shows them. Other apps may show them or simply show the plain text; nothing is lost either way.

How do I make MarkeDown open .md files when I double-click them?

In Finder, select any .md file, choose File > Get Info, pick MarkeDown under "Open with", then click "Change All…".

Which export formats are there?

Word (.docx), PDF, web page (.html), OpenDocument text (.odt), Rich Text (.rtf), EPUB e-book, plain text and JSON. Page size, margins and page numbers for PDF, Word, OpenDocument, Rich Text and printing are in Settings > Export. Pictures from the internet are not downloaded, so use local images in documents you plan to export.

Does MarkeDown need an internet connection?

No. It works completely offline. The only time it touches the internet is when you click a web link in a document, which opens in your browser.

Keyboard shortcuts

Help > Keyboard Shortcuts lists them all. The most used: ⌘B bold, ⌘I italic, ⌘K link, ⌘F find, ⌘P print, ⌘, settings.

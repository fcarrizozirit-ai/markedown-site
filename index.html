Write like a word processor.
Save plain Markdown.

MarkeDown is a visual editor for .md files. Format with a toolbar instead of symbols, and keep ordinary text files that open anywhere, today and years from now.

For Mac, on Apple silicon and Intel. Coming soon on Setapp.

No syntax to learn

Headings, lists, task lists, tables, links, quotes, code and images appear as they will look, not as symbols.

Your files stay yours

Plain .md files on your Mac. No account, no cloud, no tracking. Works completely offline.

Export anywhere

Word, PDF, web page, OpenDocument, Rich Text, EPUB, plain text and JSON, plus printing.

Made for long documents

Outline panel, tabs, find, focus mode and autosave.

Light and dark

Follows macOS or your choice, with adjustable text size, spacing and page width.

Friendly to other systems

Keeps each file's line endings, so files shared with Windows or Linux users aren't rewritten.
